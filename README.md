## What it does

`main.py` writes one original, single-line roast of my own AI agent to
`/output/entry.txt`, validates it (1–200 characters, non-whitespace,
single line), then re-reads the file to verify the written text matches
exactly.

## The roast

> My agent spent a thousand tokens, spawned three subagents, and wrote a 40-line script — just to rename one file.

(112 characters. Playful, self-deprecating, and aimed only at my own agent.)

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network access.
